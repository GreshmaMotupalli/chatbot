# Document Q&A Chatbot

A RAG-based chatbot that lets you upload PDF documents, ask questions about them, and get answers generated by a local LLM (via Ollama) using retrieved context from MongoDB.

- **Backend:** FastAPI, MongoDB, Sentence-Transformers (embeddings), Ollama (`deepseek-r1:1.5b`)
- **Frontend:** React

---

## Prerequisites

Make sure these are installed **before** cloning:

| Tool | Version | Notes |
|---|---|---|
| [Python](https://www.python.org/downloads/) | 3.10+ | Backend |
| [Node.js](https://nodejs.org/) | 18+ | Frontend (includes npm) |
| [MongoDB](https://www.mongodb.com/try/download/community) | Latest | Local database — must be running on `localhost:27017` |
| [Ollama](https://ollama.com/download) | Latest | Runs the local LLM |
| Git | Any recent | To clone the repo |

---

## 1. Clone the repository

```bash
git clone https://github.com/GreshmaMotupalli/chatbot.git
cd chatbot
```

---

## 2. Backend setup

### 2.1 Create and activate a virtual environment

```bash
python -m venv venv
```

**Windows (PowerShell):**
```powershell
venv\Scripts\Activate.ps1
```

**macOS / Linux:**
```bash
source venv/bin/activate
```

### 2.2 Install Python dependencies

```bash
pip install -r requirements.txt
```

### 2.3 Start MongoDB

Make sure MongoDB is running locally on the default port (`27017`) before starting the backend.

```bash
mongod
```

(If installed as a Windows service, MongoDB may already be running in the background — check with `mongosh`.)

### 2.4 Pull and run the Ollama model

```bash
ollama pull deepseek-r1:1.5b
ollama serve
```

`ollama serve` must stay running in its own terminal — the backend calls it at `http://localhost:11434`.

### 2.5 Start the backend server

```bash
uvicorn main:app --reload
```

The API will be available at **http://127.0.0.1:8000**.

You can check it's working by visiting **http://127.0.0.1:8000/docs** (FastAPI's auto-generated API docs).

---

## 3. Frontend setup

Open a **new terminal** (keep the backend running in the first one).

```bash
cd frontend
npm install
npm start
```

The app will open at **http://localhost:3000**.

---

## 4. Verify everything is connected

1. Go to the **Add Document** tab, upload a PDF, and click **Store Document**.
2. Switch to the **Ask Question** tab and ask something about that document.
3. Check the **History** sidebar — your question should appear there, and clicking it should reopen that Q&A.

If something fails, check the backend terminal for errors first — most issues (MongoDB not running, Ollama not running, invalid PDF) show up there with a clear traceback.

## Common issues

| Problem | Likely cause | Fix |
|---|---|---|
| `Error storing document` | PDF is corrupted or not a real PDF | Try opening the file in a PDF viewer first; re-export/re-download if it won't open |
| `Model error. Check if Ollama is running.` | Ollama isn't running, or the model isn't pulled | Run `ollama serve` and `ollama pull deepseek-r1:1.5b` |
| Backend won't connect to database | MongoDB isn't running | Start it with `mongod`, or check your MongoDB service is active |
| `Module not found: Can't resolve 'axios'` | Frontend dependencies not installed | Run `npm install` inside `frontend/` |
| CORS errors in browser console | Frontend running on a different port than `localhost:3000` | Update the `allow_origins` list in `main.py`'s CORS middleware to match |

## Environment notes

- The frontend expects the backend at `http://127.0.0.1:8000` (hardcoded in `App.js`). If you run the backend on a different host/port, update the URLs there.
- No `.env` file or API keys are required — everything runs locally (MongoDB, Ollama, and the embedding model download from Hugging Face on first run).
